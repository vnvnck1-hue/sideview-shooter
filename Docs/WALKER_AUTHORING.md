# 사족보행 피벗 · 키프레임 편집

로비에서 **사족보행 랩 — 인게임 보행 튜닝**을 열고 상단 **피벗 · 키프레임**을 누른다. 원화 위 피벗 편집 화면이 열린다. 수정한 피벗과 동작은 프로젝트의 `GodotPrototype/authoring/walker_motion.json`에 함께 저장되며, 다음에 편집기를 열 때 자동으로 불러온다. **보행 튜닝**으로 돌아가 [인게임 기체의 보폭·관절 각도](WALKER_TUNING.md)를 조정할 수 있다.

## 먼저 피벗 교정

1. **피벗 편집**에서 원화 위 십자 관절을 클릭하고 올바른 위치로 드래그한다.
2. 겹친 관절은 오른쪽 목록으로 고르거나 **전체 관절 / 몸체 / FF / FR / NF / NR** 필터로 다른 다리를 숨긴다.
3. 원본 좌표 **X/Y**를 직접 입력해도 된다. 화살표는 원화 1px, Shift+화살표는 10px 이동한다. 드래그할 때 Shift는 미세 이동, Ctrl은 5px 격자에 맞춘다.
4. 휠로 확대하고 중클릭 드래그로 화면을 움직인다. **맞춤** 또는 F로 전체 원화를 다시 맞춘다. 원화 농도 슬라이더로 그림을 흐리게 하거나 숨긴다.
5. **Ctrl+S**로 저장한다. **보행 확인**에서 교정한 관절과 길이로 걷기·후진·점프를 시험한다.

피벗 편집은 원화 기준 관절 위치와 뼈 길이를 바꾼다. 원화 이미지 자체는 고정한다. 처음 제공된 좌표와 숨겨진 네 번째 다리 해석은 사용자가 고칠 수 있는 초안이다.

보행 확인은 [거미형 공간 관절 계산](WALKER_SPIDER_GAIT.md)을 사용한다. 화면에서 짧아진 다리 길이를 실제 길이로 취급하지 않으므로, 다리가 앞뒤로 회전할 때 화면 본의 길이는 달라질 수 있다. 실제 공간의 뼈 길이는 고정이다.

## 동작의 키프레임 잡기

1. **키프레임** 탭에서 **대기 / 걷기 / 달리기 / 점프 / 사격** 중 동작을 선택한다. 이름을 입력하고 **+**를 누르면 동작을 추가할 수 있다. 기본 동작에는 원화 기준 자세 한 장만 들어 있다.
2. 타임라인을 클릭해 시간을 선택한다.
3. 뼈의 끝점을 드래그하거나 오른쪽 **관절 각도**를 입력해 자세를 잡는다. 뼈 길이를 유지하며, 연결된 자식 뼈가 함께 회전한다. Ctrl+드래그는 15도 단위로 맞춘다.
4. **자세를 바꾸면 현재 시간에 키가 자동 기록된다.** 다른 시간에 같은 자세를 찍을 때는 **키 기록 / K**를 누른다. 오른쪽 목록의 **전체 위치**는 로봇 전체를 옮겨 점프 높이·전후 움직임을 지정할 때 쓴다.
5. 금색 다이아몬드를 드래그하면 키의 **타이밍**이 바뀐다. 다이아몬드 클릭은 그 키로 이동한다. 다른 키와 겹치는 이동은 거부하므로 기존 자세가 사라지지 않는다. **키 삭제**로 선택 시간의 키를 지울 수 있다.
6. **재생 / Space**로 확인한다. 길이(초), 반복 여부, 키 사이의 보간을 바꿀 수 있다. 보간은 **부드럽게 / 선형 / 유지**이며 선택한 키에서 다음 키까지 적용된다. `유지`는 다음 키 순간에 자세를 바꾸는 블로킹 작업에 쓸 수 있다.
7. **Ctrl+S**로 저장한다. 드래그 한 번·숫자 변경·키 타이밍 이동은 각각 한 번의 실행 취소로 되돌릴 수 있다.

예: 걷기의 0.0초에 지지 자세 → 0.2초에 발을 든 자세 → 0.4초에 발을 뻗은 자세 → 0.6초에 착지 자세를 잡고 반복 재생한다. 각 시간을 옮겨 발을 빨리 떼거나 천천히 내려놓도록 리듬을 지시할 수 있다.

**기준 자세**는 키프레임 모드의 현재 시간에 원화 기준 자세를 기록한다. **보행 확인**에서 **캡처**를 누르면 그 순간의 투영된 관절 방향을 2D 키로 가져와 수정할 수 있다. 깊이에 따라 달라지는 투영 길이까지 굽는 기능은 아니다. 수동으로 기록한 키프레임은 키프레임 탭에서 재생하며, 보행 확인 탭은 교정한 피벗의 공간 보행 시험이다.

## 단축키

| 입력 | 동작 |
|---|---|
| 1 / 2 / 3 | 피벗 / 키프레임 / 보행 확인 |
| Tab | 피벗 ↔ 키프레임 |
| Ctrl+S | 피벗과 클립 파일 저장 |
| Ctrl+Z / Ctrl+Y 또는 Ctrl+Shift+Z | 실행 취소 / 다시 실행 |
| K / Delete | 현재 자세 기록 / 현재 키 삭제 |
| Space | 키프레임 재생·정지 / 보행 모드 점프 |
| 휠 / 중클릭 드래그 / F | 확대 / 화면 이동 / 전체 맞춤 |
| A/D · Shift | 보행 모드 이동 · 달리기 |
| F1 | 로비. 저장하지 않은 수정이 있으면 저장 여부 표시 |

## 저장 및 구현

- `authoring/walker_motion.json`은 원화 해시, 원본 픽셀 좌표 26개, 동작별 길이·반복·시간·전체 위치·20개 본의 기준 자세 대비 회전값을 담는다. 그림 크기를 바꾸거나 창을 확대해도 저장 좌표는 바뀌지 않는다.
- 저장 시 기존 파일은 `.bak`에 보관하고, 임시 파일 검증 후 교체한다. 손상되거나 다른 원화에 속한 파일은 덮어쓰지 않고 오류를 표시한다.
- 피벗을 바꿔도 키프레임의 상대 회전은 유지된다. 새 뼈 길이가 포즈에 반영되므로 피벗 교정을 끝낸 뒤 동작을 잡는 순서가 권장된다.
- 이 단계의 키프레임은 실제 Skeleton2D/Bone2D를 구동하는 골격 연출 지시다. 원화 파츠의 스킨 변형이나 인게임 아트 교체는 포함하지 않는다.
- `walker_authoring_data.gd`: 데이터·고정 길이 FK·보간·undo·파일 입출력. `walker_authoring_editor.gd`: 화면 관절 조작·실제 골격 연결. `walker_authoring_panel.gd` / `walker_timeline.gd`: 편집 UI.

```text
godot --headless --path GodotPrototype --script res://tools/validate_walker_authoring_data.gd
godot --headless --path GodotPrototype --script res://tools/validate_walker_authoring_editor.gd
godot --path GodotPrototype --rendering-method gl_compatibility --audio-driver Dummy --fixed-fps 60 --script res://tools/capture_walker_authoring.gd
```

검증·캡처는 테스트 경로만 사용한다. 캡처의 예시 키는 메모리에만 생성하며 사용자의 저장 파일을 변경하지 않는다.
