# 게임 기획 문서 안내

서사와 게임 플레이의 큰 방향은 [`../AI_Robot_Base_Narrative_Design_Notes.md`](../AI_Robot_Base_Narrative_Design_Notes.md)를 기준으로 한다. 초기 [`STORY_CONCEPT_DRAFT.docx`](STORY_CONCEPT_DRAFT.docx)의 고유한 공간·정보·위협·표현 원칙은 기준 문서 18~20장에 반영했다. `.docx`는 논의 당시의 초안으로 보존하며, 변경 사항을 두 곳에 중복 기록하지 않는다.

| 목적 | 문서 | 담당 범위 |
|---|---|---|
| 서사·선택의 기준 | [`AI_Robot_Base_Narrative_Design_Notes.md`](../AI_Robot_Base_Narrative_Design_Notes.md) | 핵심 설정, 구조와 자원, AI의 성장, 백업·재기동, 미정 사항 |
| 첫 25분 FTUE | [`OPENING_FLOW.md`](OPENING_FLOW.md) | 조작 학습과 9개 비트, 회수 구조, 도입부 구현 순서 |

단말기와 지도는 같은 화면을 공유하지만, 지도 생성·판독 규칙은 독립적으로 변경될 수 있으므로 합치지 않는다. 도입부 역시 전체 서사의 반복 요약이 아니라 시간별 플레이·구현 문서로 유지한다. 각 문서가 겹치는 곳은 핵심 원칙만 참조하고 상세 수치·상태는 해당 담당 문서에서 갱신한다.

방 원화 브리프 [`RETRO_STATION_ROOM_CONCEPTS.md`](RETRO_STATION_ROOM_CONCEPTS.md)는 시각 제작 자료여서 게임 서사 기준 문서에 합치지 않았다.
