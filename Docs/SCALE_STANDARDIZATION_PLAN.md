# 캐릭터·배경 규격 정립 — 그레이박스 테스트 계획

작성: 2026-09-23

- **분류: 빠른 시일 안에 착수해야 하는 작업**
- **우선순위: 높음 — 배경 타일·프랍의 본격 제작에 앞서 진행**
- **상태: 착수 대기 / 계획 정리 완료**
- 착수일·담당자: 미정
- 이번 기록의 범위: 작업 계획과 우선순위 정리. 테스트 씬 구현과 규격 확정은 후속 작업이다.

## 목적과 진행 원칙

캐릭터와 배경의 크기 기준이 일관되지 않아 공간과 소품의 비율을 판단하기 어렵다. 캐릭터가 직접 움직일 수 있는 테스트 씬에서 배경 타일과 프랍을 그레이박스로 비교하고, 검증된 치수를 제작 규격으로 정리한다. 이후 해당 규격에 맞춰 실제 배경을 제작한다.

기준을 정하는 순서는 **캐릭터 → 이동 성능 → 카메라 → 지형·프랍 → 제작 규격**이다. 타일 크기를 먼저 고정하거나 완성 아트를 반복 확대·축소하는 방식보다, 실제 플레이에서 필요한 공간을 먼저 확인한다.

모든 프랍을 같은 크기로 만드는 것이 목적은 아니다. 캐릭터 대비 비율, 배치 기준, 연결 규칙을 통일하고 소품의 크기 차이는 유지한다.

## 1. 대표 캐릭터와 이동 기준 기록

현재 플레이 가능한 대표 캐릭터 하나를 기준자로 삼는다. 기존 값을 먼저 측정하고, 변경이 필요한 값은 테스트 후보와 확정값을 구분해서 기록한다.

| 항목 | 기록할 내용 |
|---|---|
| 외형 크기 | 기본 자세에서 보이는 몸의 폭·높이. 이미지 캔버스의 여백과 구분 |
| 충돌 크기 | 실제 벽·바닥과 닿는 콜라이더의 폭·높이 |
| 배치 기준점 | 발바닥 중심 등 바닥 접점과 피벗 |
| 자세 변화 | 이동·구르기 등에서 외형과 충돌 영역이 달라지는 범위 |
| 이동 성능 | 이동 속도, 구르기 등 현재 지원하는 이동의 거리·소요 시간 |
| 점프 | 지원하거나 도입하기로 정한 경우에만 최고 높이·수평 도달 거리 측정 |
| 사격 기준 | 총구 높이, 조준 방향에 따른 위치, 탄환이 통과하는 경로 |

머리 장식이나 무기를 포함한 이미지 전체 크기를 통로의 충돌 기준으로 사용하지 않는다. 점프가 없는 현재 구조라면 점프 실험 때문에 새 이동 기능부터 만들지 않고, 통로·문·이동·사격 검증부터 진행한다.

## 2. 규격 비교용 테스트 씬 구성

본편의 캐릭터 조작과 카메라를 활용하고, 크기를 바꿀 수 있는 단순 박스로 지형과 프랍을 배치한다. 크기가 다른 후보를 나란히 두어 같은 조건에서 비교한다.

| 테스트 구역 | 비교 내용 |
|---|---|
| 평지와 기준 눈금 | 캐릭터의 기본 비율, 이동 거리, 바닥 접점 |
| 문과 통로 | 편하게 통과하는 크기, 좁게 느껴지는 폭·높이, 구르기 시 통과 여부 |
| 계단과 턱 | 현재 이동 규칙에서 통과·차단되는 높이 |
| 발판과 틈 | 점프가 대상 기능이면 쉬운·보통·한계 도달 거리 비교 |
| 상자와 엄폐물 | 캐릭터 대비 높이, 이동 차단, 총구·탄환과의 관계 |
| 벽과 천장 | 실내 높이, 여유 공간, 화면에서 느껴지는 답답함 |
| 배경 프랍 | 가구·기둥·설비의 상대 비율과 캐릭터 가림 정도 |
| 타일 연결부 | 바닥·벽·모서리의 맞물림, 반복 배치와 단차 |

각 후보에는 식별자와 치수를 표시한다. 눈금과 캐릭터 실루엣을 두고, 충돌 지형·통과 가능한 배경·상호작용 프랍은 색으로 구별한다. 규격 확인에 집중할 수 있도록 기본 비교 구역은 적 스폰 없이 구성한다.

### 기존 SpaceLab과의 관계

[`SPACE_TEST_SCENE.md`](SPACE_TEST_SCENE.md)에 기록된 `SpaceLab.tscn`은 넓은 공간과 끊김 없는 방 연결의 감각을 확인하는 씬이다. 이번에는 치수를 반복 비교하는 용도가 필요하므로 **별도 규격 테스트 씬을 두는 것을 기본안**으로 삼는다. 기존 플레이 루프·카메라·방 구성 방식의 재사용 가능성을 착수 시 확인한다.

SpaceLab의 현재 셀 크기나 층고는 측정 참고값이다. 그 값이 있다는 이유만으로 새 제작 규격으로 확정하지 않는다.

## 3. 실제 카메라로 검증

목표 화면비·기준 해상도·카메라 배율을 기록하고 같은 조건에서 후보를 비교한다. 여러 줌 배율을 지원하면 주 플레이 배율을 먼저 정한 뒤 나머지 배율에서 가독성을 확인한다.

- 캐릭터와 문·상자·가구가 같은 공간에 속한 크기로 보이는가?
- 통과할 수 있는 곳과 막힌 곳이 실제 충돌 결과와 일치하는가?
- 이동·구르기·사격 시 외형이 벽에 과도하게 겹치거나 탄환이 예상과 다르게 막히지 않는가?
- 진행 방향의 공간과 장애물을 충분히 미리 볼 수 있는가?
- 큰 프랍이 캐릭터나 상호작용 대상을 지나치게 가리지 않는가?

한 번에 여러 기준을 바꾸지 않고, 후보별 치수·카메라 조건·플레이 소감·채택 이유를 함께 남긴다. 상세 조명과 장식은 규격 비교 이후에 추가한다.

## 4. 제작 규격 확정

아래 표의 실제 수치는 테스트 결과로 채운다. 이 문서는 아직 새로운 크기나 출력 배율을 확정하지 않는다.

| 규격 | 확정할 내용 | 상태 |
|---|---|---|
| 캐릭터 기준 | 외형·콜라이더·바닥 접점, 대표 자세 | 미정 |
| 카메라 기준 | 화면비·기준 해상도·주 배율과 검수할 추가 배율 | 미정 |
| 기본 그리드 | 월드 좌표 단위, 타일 폭·높이, 세부 배치용 보조 그리드 | 미정 |
| 이미지 대응 | 소스 이미지 픽셀과 월드 크기의 대응, 런타임 스케일 | 미정 |
| 건축 치수 | 문·통로·층고·턱·발판의 권장 치수와 허용 범위 | 미정 |
| 프랍 치수 | 상자·가구·설비 등의 크기군과 캐릭터 대비 비율 | 미정 |
| 조립 규칙 | 피벗·바닥 접점·타일 연결 위치·장식 돌출 허용 범위 | 미정 |
| 충돌 규칙 | 충돌 영역과 시각적 장식의 구분, 사격 차단 여부 | 미정 |

이미지 캔버스 크기, 실제 그림이 차지하는 영역, 픽셀 표현의 밀도, 월드 배치 크기는 서로 구분해서 기록한다. 규격 확정 시 기존 [`ART_GUIDE.md`](ART_GUIDE.md), [`CHARACTER_ART_GUIDE.md`](CHARACTER_ART_GUIDE.md), [`RESOURCE_USAGE_GUIDE.md`](RESOURCE_USAGE_GUIDE.md)의 관련 항목을 정합화하고 수치의 단일 기준 문서를 정한다. 그전까지 후보값을 기존 확정 규격처럼 사용하지 않는다.

## 5. 실제 아트로 소규모 검증 후 확장

먼저 바닥·벽 타일, 문, 상자만 확정 후보 규격에 맞춰 제작하고 그레이박스 일부를 교체한다. 실제 아트의 윤곽·장식·명암이 들어간 뒤에도 비율, 연결부, 충돌, 가독성이 유지되는지 확인한다.

이 검증을 통과하면 배경 타일과 프랍의 제작 범위를 넓힌다. 테스트 씬은 이후 새 에셋을 반입할 때 크기를 확인하는 검수용 씬으로 유지한다.

## 착수 순서와 산출물

1. **첫 작업:** 대표 캐릭터와 현재 카메라·이동 수치를 측정해 기준표 초안 작성.
2. **첫 플레이 가능 결과:** 평지, 문·통로, 층고, 상자 비교 구역과 치수 표시가 있는 테스트 씬 구성.
3. **비교·조정:** 동일한 카메라 조건에서 후보를 플레이하고 채택·보류 이유 기록.
4. **규격 초안:** 그리드·이미지 대응·건축·프랍·피벗·충돌 규칙 정리.
5. **아트 검증:** 최소 타일·문·상자를 적용해 검수하고 규격 확정.

## 완료 기준

- [ ] 대표 캐릭터의 외형·충돌·이동·사격 기준이 기록되어 있다.
- [ ] 캐릭터가 직접 움직이며 후보 치수를 비교할 수 있는 테스트 씬이 있다.
- [ ] 카메라 조건과 후보별 치수·판단 근거가 기록되어 있다.
- [ ] 기본 타일·건축·프랍의 규격과 배치·연결 규칙이 정리되어 있다.
- [ ] 바닥·벽·문·상자의 실제 아트 적용 결과를 확인했다.
- [ ] 확정 규격이 관련 제작 문서와 일치하고, 후보값과 확정값이 구별된다.

우선순위를 높게 두는 이유는 이후의 배경 제작·프랍 배치·방 구성에서 발생할 크기 재작업을 줄이기 위해서다. 기존 작업 목록의 자산 구조화와 연결하되, 배경 에셋의 본격적인 추가 제작 전에 이 기준부터 검증한다.
