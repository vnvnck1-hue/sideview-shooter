# 규격 테스트 씬 실측 결과

`tools/validate_scale_lab.gd` 가 자동으로 만든 문서다. 손으로 고치지 말고 툴을 다시 돌린다.

- 실행: `godot --path . --headless --fixed-fps 60 --script res://tools/validate_scale_lab.gd`
- 방식: 실제 ScaleLab 플레이 루프에서 오른쪽 이동 입력을 넣고, 구르기는 22프레임마다 다시 누른다 (최대 8회).
- 통과 = 판정 상자(폭 124) 전체가 지형 반대편으로 나감. 수치는 모두 **후보**다.
- 해석과 채택 여부: [`SCALE_TEST_SCENE.md`](SCALE_TEST_SCENE.md)
