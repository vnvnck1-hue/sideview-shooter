# 인게임 사족보행 조정

로비 → **사족보행 랩 — 인게임 보행 튜닝**을 연다. `WalkerLab.tscn`은 본편과 같은 `ProcWalker`, 거미형 공간 관절 계산, `WalkerRig` 아트를 사용한다. 저장한 원화의 다리 피벗도 그대로 읽는다. 화면은 조정하기 편하게 확대되어 있다.

오른쪽 탭에서 슬라이더를 움직이거나 숫자를 입력하면 현재 기체에 즉시 적용된다. 자동 걷기를 켜 두고 값을 바꾸면 변화를 계속 비교할 수 있다. **정지 / ← 걷기 / 걷기 →**, **달리기**, **점프**, **일시정지**, **본 겹쳐보기**를 제공한다. 평지·오르막·내리막도 선택할 수 있다.

| 탭 | 조정값 |
| --- | --- |
| 자세 | 이동 속도, 몸 높이, 발 벌림 |
| 걸음 | 스텝 시작 오차, 발 들기 높이, 걷기·달리기 스텝 시간, 접지 대기, 착지 위치 선행, 동시에 드는 발 |
| 몸 | 지형 기울기 추종, 상하 리듬, 조준 몸 기울기 |
| 각도 | 골반 앞뒤·위아래 기준 각도, 무릎 벌림 각도 |
| 범위 | 골반 수평·수직 회전 허용 범위 |

`발 벌림`은 앞뒤 발 간격이고, `스텝 시작 오차`와 `착지 위치 선행`은 발을 옮기는 시점과 실제 보폭을 함께 결정한다. 동시에 드는 발이 1이면 세 발 지지 순차 보행, 2이면 대각 쌍 교대 보행이다. 관절 각도는 공간에서 계산하며 발 접지와 물리적인 뼈 길이는 유지한다. 도달 범위를 줄이거나 몸을 과하게 높이면 가능한 속도·보폭도 줄어든다. `지형 기울기 추종`은 오르막·내리막에서 비교한다.

**저장 / Ctrl+S**는 `GodotPrototype/authoring/walker_gait.json`에 기록한다. 다음에 생성되는 인게임 로봇과 테스트씬이 이 설정을 함께 읽는다. 본편으로 다시 진입하면 저장값이 적용되며, 미리보기만 바꾼 상태에서는 파일이 바뀌지 않는다. 기존 파일은 `.bak`으로 보관하고, 손상되거나 지원하지 않는 파일은 덮어쓰지 않는다.

**불러오기**는 마지막 저장값으로, **기본값 / F5**는 기본 보행으로 돌아간다. **Ctrl+Z**로 수치 조정과 불러오기·기본값 복귀를 취소할 수 있다. **포즈 초기화**는 조정한 수치를 유지하며 위치·접지 자세만 초기화한다. 저장하지 않고 다른 화면으로 이동하면 저장 여부를 선택한다.

상단 **피벗 · 키프레임**으로 기존 [원화 편집기](WALKER_AUTHORING.md)를 열고, 그 화면의 **보행 튜닝**으로 돌아온다. 피벗·키프레임은 `walker_motion.json`, 보행 수치는 `walker_gait.json`에 각각 저장한다. 원화 편집기의 `보행 확인`은 원화 뼈대를 보는 화면이며, 인게임 수치의 비교는 새 보행 튜닝 화면에서 한다. 수동 키프레임의 인게임 자동 재생은 기존 범위와 같다.

## 단축키

| 키 | 동작 |
| --- | --- |
| A/D 또는 ←/→ · Shift · Space | 이동 · 달리기 · 점프 |
| 마우스 · 좌클릭/J | 독립 조준 · 사격 (미리보기 영역에서) |
| F2 · F5 · F9 · F1 | 본 겹쳐보기 · 기본값 · 수치 출력 · 로비 |
| Q/Z · E/C · R/V | 속도 · 발 벌림 · 몸 높이 올림/내림 |
| T/B · Y/N · U/M | 스텝 시작 오차 · 발 높이 · 스텝 시간 올림/내림 |
| I/, · O/. · P/슬래시 | 선행 · 접지 대기 · 동시 스윙 발 수 올림/내림 |
| [/] · ;/' | 지형 기울기 · 조준 몸 기울기 내림/올림 |

숫자 입력 중에는 보행·수치 단축키를 받지 않는다. 입력 후 바로 저장하거나 탭을 바꾸어도 입력한 값이 먼저 확정된다.

## 검증

```text
godot --headless --path GodotPrototype --script res://tools/validate_walker_gait_settings.gd
godot --headless --path GodotPrototype --script res://tools/validate_walker_tuning_runtime.gd
godot --headless --path GodotPrototype --script res://tools/validate_walker_tuning_lab.gd
godot --path GodotPrototype --rendering-method gl_compatibility --audio-driver Dummy --fixed-fps 60 --script res://tools/capture_walker_tuning.gd
```
