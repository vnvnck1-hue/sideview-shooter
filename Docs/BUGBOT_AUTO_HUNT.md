# 버그봇 자동 사냥 전투 (임시 연출)

플레이 화면에서 **F10**을 누르면 플레이어가 있는 바닥 구간에 버그봇 3대가 소환된다. 다시 F10을 누르면 소환 기체와 이번 전투에서 생성한 몬스터를 회수하고 원래 방의 스폰을 재개한다. 방 이동·로비 복귀 시에도 자동 해제된다. 대화·단말기·기체 조종·방 전환 중에는 단축키를 받지 않는다.

- 기존 버그봇 리그, 보행, 포탑 선회, 총구 화염, 산포, 과열을 공유한다. 플레이어는 계속 직접 이동·사격할 수 있다.
- 가까운 몬스터를 탐색하고 다른 기체의 표적에 가중치를 주어 표적을 분산한다. 기체 간 간격을 유지하며 사거리로 이동하고, 포신 정렬과 벽 가림을 확인한 뒤 점사한다.
- 몬스터는 같은 구역의 작동 중인 버그봇을 우선 공격한다. 독액과 거대종의 내려찍기가 기체 장갑을 깎는다. 장갑 100, 독액 기본 피해 14, 내려찍기 28. 전투불능 시 7초간 수리 후 다시 기동한다. 청록색 막대는 장갑, 주황색은 수리 진행이다.
- 일반종 12발, 거대종 48발 기준으로 이 전투에서 생성하는 몬스터의 체력을 설정한다. 기존 배치 개체의 체력은 유지한다. 매 5번째 증원은 천장·이동 폭이 허용하면 거대종이다.
- 생성 목표는 4초마다 `살아 있는 기체의 장갑 비율 합 × 2.6 + 최근 초당 처치 수 × 2.5`로 조정한다(3~14마리). 처치 속도는 4초 관측 구간에 지수 평활을 적용한다. 장갑 비율은 작동 기체당 최소 0.35로 계산한다.
- 보충 간격은 `1 / (전투력 × 0.3 + 최근 초당 처치 수 × 1.1)`초로 계산하고 0.35~2초로 제한한다. 무조건 물량을 누적하지 않고 목표 개체 수와 방 전체 14마리 상한을 함께 확인한다.
- 플레이어 주변 1,650px 밴드에서 좌우 교대로 증원한다. 플레이어 380px / 기체 340px 안에는 생성하지 않으며, 닫힌 구역 문과 천장 높이를 고려한다. 안전한 위치가 없으면 생성을 다음으로 미룬다. 감독이 만든 먼 개체는 회수한다.
- 기존 방 구조와 같은 수평 바닥 이동을 사용한다. 다른 층으로 점프해 쫓는 내비게이션은 포함하지 않는다.

구현: `bugbot_hunter.gd`(기체 AI), `bugbot_battle.gd`(소환·전투 조절), `main.gd`(입력·사격·상태 안내). 조절 수치는 각 스크립트 상단과 전투 감독의 `_process()`에 있다.

검증: `godot --headless --path GodotPrototype --fixed-fps 60 --script res://tools/validate_bugbot_battle.gd`. 실제 F10 입력, 3대의 이동·사격·처치, 반격·수리, 물량 조절, 상한, 종료·재소환·방 이동을 검사한다. 기존 조종 회귀 검사는 `tools/validate_walker_unit.gd`다.
