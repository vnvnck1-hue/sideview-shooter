# 배경 제작 방향 — 얕은 사이드뷰 공간과 상호작용 위계

2026-09-22 확정 기록. **앞으로 방 배경 원화를 제작할 때 적용할 현재 방향**이다. 이번 메탈슬러그 조사와 시안 피드백에서 도출했다.

> 넓이는 가로로 이어지는 건축과 큰 설비로 만들고, 깊이는 얕은 면의 단차와 겹침으로 제한한다. 캐릭터 뒤에 가까운 벽이 있는 사이드뷰 무대를 유지한다. 고정 배경과 조작 프랍은 고유색을 보존하면서 명암·윤곽·디테일의 위계로 구분한다.

최상위 보존 원칙과 엔진 호환 규격은 [ART_GUIDE](ART_GUIDE.md), 조사·수치·피드백 이력은 [BACKGROUND_RESEARCH_LOG](BACKGROUND_RESEARCH_LOG.md), 개별 시안의 **현재 선택·승인 상태는 [ART_ASSET_STATUS](ART_ASSET_STATUS.md)**가 담당한다. 이 문서는 기존 이미지 교체나 게임 구현을 승인하지 않는다.

## 1. 적용 범위와 기준 이미지

대형 정비홀, 전력 릴레이실 및 이후 제작할 방의 **공간 구도·배경 조형·프랍 가독성**에 적용한다. 과거 자산의 원화·제작 원본은 소급해서 다시 그리지 않는다. 새로운 방의 주제에 맞는 장비는 새로 설계할 수 있지만, 그림체와 아래 공간 문법은 유지한다.

### 공간과 그림체 기준

- [대형 정비홀 v1](../research-images/comparison/hall-redesign-v1.png): 넓은 건축 덩어리, 벽 가까이 붙는 설비, 좁은 바닥, 큰 캐릭터가 유지되는 **선호 공간 참조**다. 모든 프랍의 디자인·색·배치를 재사용하라는 뜻은 아니다.
- [전력 릴레이실 v1](../research-images/comparison/power-relay-concept-v1.png): 같은 공간 문법을 다른 방 기능에 옮긴 참조다. 전체 방향에 긍정 피드백이 있었지만 **고정 배경/상호작용 프랍의 톤 구분은 부족**했다.
- [전력 릴레이실 v2 — 상호작용 구분](../research-images/comparison/power-relay-concept-v2-interaction.png): 구분 효과는 인정되어 **현재 결과를 그대로 유지**한다. 다만 사용자는 배전반의 고유색을 바꾼 결과를 마음에 들어 하지 않았다. **재색칠 방식의 선호·표준 승인으로 해석하지 않는다.**
- [대형 정비홀 v2](../research-images/comparison/hall-redesign-v2.png): 바닥과 근경의 깊이가 과해 미채택했다. 신규 방의 공간 기준으로 사용하지 않는다. 비교·실패 기록으로 보존한다.

현재 시안 유지와 미래 제작 방식은 구별한다. **전력실 v2를 이 문서 때문에 자동으로 되돌리거나 다시 칠하지 않는다.** 다음 수정이 요청되면 고유색을 보존하는 대안을 별도 버전으로 제시한다.

## 2. 공간 문법: 넓지만 얕게

### 유지할 것

- 정면성이 강한 횡스크롤 구도, 연속된 수평 이동선, 가까운 뒤벽.
- 화면 가로로 이어지는 굵은 골조, 천장 설비, 큰 장비 실루엣. 세계가 프레임 밖으로 이어지는 인상은 허용한다.
- 소품의 윗면·한쪽 측면, 문틀 두께, 설비 받침, 국소적인 벽 요철 정도의 **약한 원근**.
- 현재 캐릭터의 존재감. 배경의 웅장함을 만들려고 캐릭터부터 작게 만들지 않는다.
- 큰 형태 → 중간 연결 구조 → 제한된 작은 마감의 순서. 조용한 큰 면도 구성 요소로 남긴다.

### 채택하지 않는 것

- 넓은 바닥을 통해 멀리 떨어진 뒤벽까지 시선이 빨려 들어가는 홀·광장·복도 구도.
- 화면 하단을 대형 드럼·곡관·기계 덩어리로 크게 채워 별도의 깊은 전경 공간을 만드는 방식.
- 아이소메트릭·높은 부감·강한 3/4 시점, 중앙 소실점이 지배하는 터널.
- 캐릭터 발을 위로 크게 옮기고 앞쪽 바닥을 확장했던 정비홀 v2의 구도.
- 공간감 개선을 곧바로 카메라 줌·화면비·충돌·이동 규칙 변경으로 해석하는 것.

정비홀 v1·전력실 프롬프트의 발 위치 약 87~89%, 캐릭터 높이 약 21~22%, 약 2.49:1 화면비는 **이번 참조 시안의 재현 보조값**이다. 모든 방의 강제 규격이나 새 엔진 카메라 설정이 아니다. 수치보다 기준 이미지와 같은 얕은 공간감을 우선한다. 초기 디오라마의 방 너비 85%·높이 70%와 외부 암부 여백도 새 배경의 필수 비율로 적용하지 않는다.

## 3. 바닥과 근경

바닥의 역할은 이동선과 접지를 읽게 하는 것이다. 얇은 윗면, 재질 이음새, 설비의 받침과 접촉 그림자만으로 입체를 설명하고, ‘바닥 면적이 넓을수록 좋다’고 판단하지 않는다.

근경은 기존 검은 상자나 기둥을 복제할 필요가 없다. 방 기능에 맞는 짧은 배관, 케이블 묶음, 프레임 조각 등으로 새로 구성할 수 있다.

- 하단 모서리·좌우 끝에 제한적으로 걸치게 한다.
- 중앙 이동선, 플레이어 실루엣, 조작 대상의 손잡이·레버를 가리지 않는다.
- 몸체는 차분한 암부로 읽히되, 볼트와 모서리마다 강한 광택을 넣지 않는다.
- 긴 검은 수직 막대나 연속된 검은 장벽으로 화면을 분할하지 않는다.
- 이번 시안의 하단 약 5~10% 언급은 방향 설명이지 모든 방의 수치 상한이 아니다. 실제 가림과 시선 경쟁으로 검수한다.

## 4. 방의 주제와 프랍 역할을 먼저 정한다

배경을 그리기 전에 주요 형상의 역할을 나눈다. ‘기계처럼 보인다’는 것과 ‘플레이어가 사용할 수 있다’는 것은 다르다.

| 역할 | 제작 시 확인할 질문 | 표현 목표 |
|---|---|---|
| 고정 건축·설비 | 문맥을 설명하지만 사용/파괴하지 않는가? | 큰 형상은 읽히고 작은 디테일은 조용하게 |
| 상호작용 프랍 | 어떤 부위를 조작·회수·파괴하는가? | 실루엣과 실제 기능 부위가 즉시 읽히게 |
| 인물·전투 대상 | 움직임과 상태를 먼저 읽어야 하는가? | 핵심 식별색과 실루엣의 우선순위 확보 |
| 근경 장식 | 공간 테두리를 잡는 비상호작용 요소인가? | 시선을 빼앗지 않는 제한적 가림 |

전력실 시험에서 ‘오른쪽 배전반은 조작 대상, 왼쪽 코일은 고정 배경’으로 정한 것은 **시안용 가정**이다. 실제 게임의 상호작용 사양으로 확정하거나 코드를 연결한 것이 아니다. 새 방에서는 역할을 브리프에서 확인하고 미정 항목은 미정이라고 표시한다.

방 기능에 맞는 새 프랍을 만든다. 정비실에는 정비 설비, 전력실에는 코일·절연체·계기·배선처럼 원인이 있는 구조를 둔다. 장비를 일정 간격으로 나열하거나 기존 작업대·캐비닛으로 모든 방을 채우지 않는다. 그렇다고 기존 승인 프랍을 모두 폐기해야 한다는 뜻은 아니다.

## 5. 상호작용 위계: 고유색 보존이 전제

이번 문제는 물체들이 같은 계열 색이라서만 생긴 것이 아니다. 고정 코일·흰 절연체·볼트까지 조작부와 비슷한 강도의 광택·윤곽·세부 대비를 가져 **시각적 중요도가 평준화**되어 있었다.

### 고정 배경

- 큰 면과 소재의 성격은 유지하면서 국소 명암 폭을 좁힌다.
- 작은 볼트·마모·고정 코일의 광택이 조작부보다 먼저 읽히지 않게 묶는다.
- 조작 프랍 바로 뒤는 형태를 분리할 수 있도록 차분한 면으로 정리한다.
- 배경을 통째로 검게 만들거나 흐리게 처리하지 않는다. 픽셀 경계는 선명하게 남긴다.
- 모든 배경을 동일한 청색으로 재색칠하라는 뜻이 아니다. 방·소재 고유색을 보존한다.

### 상호작용 프랍

- 먼저 승인된 고유색·재질·형태를 유지한다. **구별을 위해 통째로 노랑·주황으로 바꾸는 것을 기본 해법으로 삼지 않는다.**
- 배후 정리와 주변 대비를 통해 기존 실루엣·밝은 면·어두운 틈이 살아나게 한다.
- 레버·손잡이·계기 등 실제 기능 부위에 디테일을 집중한다.
- 새 원화에서는 실루엣과 내부 기능을 설명하는 명암을 의도적으로 설계한다. 기존 승인 원화에 없는 밝은 림·검은 링·새 강조색을 후처리 단계에서 임의 추가하지 않는다.
- 프랍 전체의 명도·채도를 일괄 올리거나 발광 외곽선으로 해결하지 않는다. 프랍 자체 수정이 꼭 필요하면 변경 부위와 이유를 제시하고 별도 확인을 받는다.

### 현재 전력실 v2의 예외

사용자 피드백은 **“컬러 자체를 바꿔서 맘에 안들지만, 우선 구별은 되니까 그냥 그대로 둬야겠어.”**다.

따라서 효과와 선호를 분리한다.

- 효과: 고정 설비와 조작 대상으로 가정한 배전반이 구별됨.
- 선호: 고유색을 바꾼 방식은 마음에 들지 않음.
- 현재 조치: 해당 시안은 그대로 유지.
- 미래 규칙: 색 교체를 표준화하지 말고 고유색 보존 안에서 위계를 설계.
- 미승인: 픽셀화, 모듈 분리, 게임 반입, 실제 배전반 상호작용 구현.

시선 우선순위는 **캐릭터/전투 정보 → 조작 프랍 → 고정 배경 → 비상호작용 근경 장식**이다. 이것은 모든 물체의 절대 밝기를 같은 순서로 정하라는 뜻이 아니다. 국소 대비·면적·실루엣·시선 경쟁을 함께 판단한다.

## 6. 픽셀·조명·소실점의 경계

- 픽셀 크기, 하이라이트 폭, 윤곽과 디테일 덩어리가 같은 장면 안에서 같은 그림체로 읽혀야 한다. 고정 배경의 중요도를 낮춘다는 이유로 블러를 쓰지 않는다.
- 분석에서 확인된 작업실 벽의 미세 색 변화와 4×4 소품의 차이는 진단이다. 기존 파일을 이 문서만으로 자동 변환하지 않는다.
- 배경·프랍 전체에 고정 8~16색을 강제하지 않는다. 캐릭터의 별도 목표와 승인 원화 보존 기준은 [ART_GUIDE](ART_GUIDE.md)를 따른다.
- AI 생성 그림은 원화 시안이다. 픽셀 격자·팔레트·피벗·알파·반입 규격이 검증된 게임용 스프라이트가 아니다.
- 조명은 이미 그려진 면과 역할 위계를 보조한다. 램프·발광·CRT로 배경과 프랍의 대비 차이를 다시 지우지 않는다. 원화 표현과 런타임 광원 정책은 구분한다.
- 발 접지선·눈높이·화면 중심은 서로 다르다. ‘눈높이 40~55%’ 또는 ‘메탈슬러그는 단일 중앙 소실점’은 제작 규칙으로 쓰지 않는다.
- 같은 방향의 평행 모서리는 일관되게 수렴해야 한다. 방향이 다른 물체는 소실점이 달라도 되지만 공통 눈높이와 접지 관계가 모순되어서는 안 된다. 카메라가 2D라는 사실은 PNG 내부의 투시가 없다는 뜻이 아니다.

## 7. 이후 배경 제작 순서

1. **기준 확인:** 이 문서, ART_GUIDE §0, ART_ASSET_STATUS를 읽고 사용할 정확한 참조 버전을 지정한다. 정비홀 v2를 기준으로 잘못 선택하지 않는다.
2. **방 브리프:** 방의 기능, 핵심 설비, 이동선, 캐릭터 크기, 고정 배경/상호작용 프랍/근경의 역할, 보존할 고유색을 기록한다.
3. **얕은 공간 러프:** 큰 건축·장비와 빈 면을 먼저 배치한다. 과도한 지면 원근이나 작은 캐릭터로 공간을 키우지 않는다.
4. **역할 위계 설계:** 같은 색을 유지한 채 배경 대비·배후 면·기능 부위·실루엣을 정리한다. 기능색이 필요한 새 디자인은 처음부터 브리프에 명시한다.
5. **원화 생성·수정:** 기존 기준의 그림체로 방마다 새로운 설비를 설계한다. 한 번에 비교할 변경 항목을 분명히 하고, 프롬프트·입력 참조·출력 버전을 보존한다.
6. **시각 검수:** 원본 크기, 실제 표시 크기, 축소, 흑백에서 공간·역할·색 보존을 확인한다. 구분 효과가 생겼더라도 팔레트 선호까지 승인됐다고 쓰지 않는다.
7. **사용자 판단 기록:** 선호/미채택/임시 유지/추가 수정/미확정을 나누어 ART_ASSET_STATUS에 기록한다. 최신 버전이 자동으로 기준 버전은 아니다.
8. **제작 전환:** 원화 승인 후에만 [ASEPRITE_PIPELINE](ASEPRITE_PIPELINE.md)로 보존형 픽셀화를 진행한다. 방 전체 이미지와 개별 배경·프랍·근경 모듈은 별도 산출물로 관리한다.
9. **반입 검수:** 레이어, 가려진 면, 접지, 타일 이음새, 피벗, 조명·CRT와 실제 상호작용을 확인한다. 콘셉트 방향 합의와 게임 적용 승인은 분리한다.

## 8. 제출 전 체크리스트

- [ ] 정비홀 v1·전력실 v1 계열의 얕은 측면 구도인가?
- [ ] 큰 건축과 설비가 가로 공간을 만들고, 벽지 반복이나 넓은 원근 바닥이 구도를 지배하지 않는가?
- [ ] 고정 배경과 조작 대상의 역할이 브리프에 명시되었는가?
- [ ] 사용자가 원하는 색·소재를 보존했는가? 구별을 이유로 새 색으로 덮지 않았는가?
- [ ] 배경은 읽히되 작은 반짝임과 세부가 조작부와 경쟁하지 않는가?
- [ ] 프랍의 실루엣과 기능 부위가 읽히고, 플레이어가 우선 보이는가?
- [ ] 근경이 얕은 테두리 역할에 머물고 이동·조작 대상을 가리지 않는가?
- [ ] 원근·접지·픽셀 덩어리·빛이 서로 일관되는가?
- [ ] 시안/원화 승인/픽셀 결과 승인/게임 적용 상태를 구별했는가?
- [ ] 미채택본과 프롬프트를 남기고 현재 선택 상태를 갱신했는가?

## 9. 이번 기록이 승인하지 않은 작업

이번 문서화는 이후 배경의 **미술 제작 방향을 기록하는 작업**이다. 현재 런타임 배경 일괄 교체, 카메라 배율 변경, 방 크기 변경, 게임 판정·충돌·상호작용 구현, 기존 자산 감색·재색칠을 수행하거나 승인한 것이 아니다. 과거 문서의 Native8/Power Relay 테스트 폐기는 옛 렌더 실험을 뜻하며, 이번 새 전력 릴레이실 콘셉트와 혼동하지 않는다.
