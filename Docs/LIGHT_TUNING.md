# 조명 수치 — 실제 플레이 화면에서 고치고 저장하기

*2026-09-22 · 로비 → **조명·면 랩** (`scenes/FaceLab.tscn`)*

## 무엇이 달라졌나

반경·세기·높이가 광원 스크립트마다 상수로 박혀 있었다. 하나 바꾸려면 파일을 열고 숫자를 고친 뒤
게임을 다시 띄워야 했고, 그래서 "조금 더 밝게" 같은 판단을 눈으로 반복하기가 어려웠다.

이제 전부 `scripts/light_tuning.gd` 한곳에 모여 있고, 랩에서 **실제로 플레이하면서** 고르고 슬라이더로
움직인 뒤 저장하면 `lighting/tuning.json` 에 쓰인다. 게임은 시작할 때 그 파일을 읽으므로 **본편에 그대로 적용된다**
(앰비언스 랩 `ambience/tuning.json`, 그림자 랩 `shadow/tuning.json` 과 같은 규약).

**파일이 없으면 기본값 = 지금까지 코드에 박혀 있던 값 그대로**다. 저장하기 전까지 게임은 이전과 완전히 똑같다.

## 랩은 게임 그 자체다

`scripts/face_lab.gd` 는 `main.gd` 를 상속한다. 플레이어·총·몬스터·카메라·방·조명이 전부 본편과 같은
코드·같은 수치로 돌아간다. 별도의 실험용 광원을 두지 않는 것이 요점이다 — **여기서 보이는 그림이 곧 인게임
그림이라야** 여기서 맞춘 값을 믿을 수 있다. (대화 UI 랩·근경 랩과 같은 생각.)

게임 조작은 본편과 동일하다: `A`/`D` 이동 · 마우스 조준 · **좌클릭 사격** · `R` 재장전 · `Space` 구르기 ·
`W`/`↑` 문·대화 · `F3` 줌 · `F6`/`F8` 그림자 · `F1` 로비.

## 랩 조작

| | |
|---|---|
| `F5` | 편집 패널 접기/펴기 |
| **우클릭** | 화면에서 고르기 — 커서에서 260px 안의 광원, 없으면 커서 아래 프랍 |
| `Tab` / `Shift+Tab` | 광원 종류 순환 |
| `G` / `Shift+G` | **총 계열만** 순환 (쏠 때만 켜져서 클릭할 수 없다) |
| `F10` | 조명 수치 저장 (패널의 [저장] 버튼과 같다) |
| **`P`** | **마우스 광원** 켜기/끄기 — 포인터가 곧 광원이 된다 (`Shift+P` 그 자리에 고정) |
| 휠 | 마우스 광원 반경 · `Shift`+휠 세기 · `Ctrl`+휠 높이 (켜져 있을 때만 휠을 가로챈다) |
| `N` | 면 노멀 ↔ 자동 노멀 A/B · `M` 면 맵 겹쳐 보기 · `F12` 면 맵 다시 읽기 |

패널 위에 커서가 있는 동안에는 사격·이동이 먹지 않는다 (사격이 액션 폴링이라 UI 가 자동으로 막아 주지 않아
`player.input_enabled` 를 직접 끈다).

## 마우스 광원 (탐침)

`P` 로 켜면 포인터가 곧 광원이 된다. 면 맵·재질을 훑어보거나 "이 각도에서 어떻게 보이나"를 확인할 때 쓴다.

**켤 때마다 천장 램프와 같은 수치(반경 560 · 세기 1.00 · 높이 140)에서 시작한다.** 그래서 휠로 벌린 만큼이
곧 "실제 램프와 얼마나 다른 빛인가" 가 되고, 패널에 `(천장 램프와 같음)` / `(램프와 다름)` 으로 표시된다.
랩에서만 쓰는 탐침이라 **저장되지 않고 본편에는 존재하지 않는다** — 이 빛으로 판단한 것은 인게임과 다를 수 있다.

## 다루는 광원

| id | | 기본 반경 / 세기 / 높이 | 비고 |
|---|---|---|---|
| `ambient` | 앰비언트 | 세기 ×1.0 | `Lighting.AMBIENT`(0.42,0.43,0.55)에 곱한다 |
| `lamp` | 천장 램프 (깨지는 것) | 560 / 1.0 / 140 | 방의 주 광원 |
| `lamp_pool` | 램프 바닥 풀 | 400 / ×0.35 / 90 | 세기는 램프 대비 비율 |
| `fixture` | 벽등·장식 조명 | ×1.0 / 1.0 / 140 | 반경은 `RoomData` fixtures.radius 에 곱하는 배율 |
| `terminal` | 단말기 화면등 | ×1.0 / ×1.0 / 140 | 역할(TerminalData)에 곱하는 배율 |
| `beacon_beam` | 비상등 회전 빔 | 720 / 1.7 / 110 | 원형이 아니라 빔 텍스처 |
| `beacon_glow` | 비상등 글로우 | 260 / 0.55 / 60 | |
| `fire` | 불 (주) | 950 / ×1.0 / 130 | 세기는 불 종류별 `energy_base`(1.5~2.0)에 곱하는 배율 |
| `fire_core` | 불 심 | 320 / 1.6 / 70 | |
| `wire` | 끊어진 전선 아크 | 260 / 2.4 / 80 | 터질 때만 |
| `muzzle` | 총구 화염 | 420 / 2.6 / 90 | **총 계열** — `G` 로 고른다 |
| `muzzle_hold` | 총구 상시등 (플레이어) | 563 / 1.8 / 90 | **총 계열** |
| `impact` | 탄착 섬광 | 260 / 2.2 / 90 | **총 계열** |
| `spark` | 불꽃 스파크 | 240 / ×1.0 / 90 | **총 계열** |

`×` 가 붙은 것은 **배율**이다 (1.0 이 지금 그대로). 방 데이터나 역할이 값을 정하는 것은 절대값으로 덮으면
방마다 다르게 잡아 둔 연출이 통째로 뭉개지므로 배율로 둔다.

## 반영 방식

- **상시 광원**(램프·벽등·비상등·불·전선·단말기)은 만들어질 때 자기를 `LightTuning.register()` 에 등록한다.
  랩이 슬라이더를 움직이면 `apply_all()` 이 살아 있는 광원 전부에 다시 먹인다 — 게임을 다시 띄울 필요가 없다.
  깜빡임·파괴 같은 제 상태를 지켜야 하는 것은 각자 `apply_tuning()` 을 들고 있다.
- **총 계열**은 쏠 때마다 새로 만들어지므로 그 순간 값을 읽는다. 등록하지 않는다 (슬라이더를 움직인 뒤
  다음 발부터 바로 반영된다).

## 매달린 램프

천장 램프(`lamp`)는 **줄에 매달려 흔들린다**. 줄의 물리는 끊긴 전선과 같은 것을 쓴다
(`scripts/rope_chain.gd` — 버렛 체인을 공용으로 꺼낸 것).

- **방에 들어선 순간에는 완전히 멈춰 있다.** `setup(tilt: 0, slack: 1)` 로 평형 상태에서 시작한다
  (비스듬히·짧게 시작하면 첫 프레임에 길이 제약이 당기면서 조명이 저절로 출렁이며 시작한다).
  줄은 `_physics_process` 에서 고정 dt 로 돈다 — 버렛은 dt 가 튀면 그만큼 에너지가 들어와서,
  방을 조립하는 프레임처럼 한 번 끊길 때 저절로 흔들린다.
- 평소엔 미풍에 아주 천천히 표류한다 (`CORD_WIND` 14 → 2.5초 최대 기울기 **0.63°**). 흔들린다고 할 정도는 아니다.
- 총에 맞으면 `LampLight.MAX_HP`(3)만큼 버틴다. 맞을 때마다 `HIT_KICK` 으로 줄을 밀어 흔들리고
  (한 발에 최대 **약 14°**) 지직거리며 유리 파편이 튄다. 체력이 다해야 깨지고, 깨진 뒤에도 갓이 계속 흔들린다.
- 스친 총알·충격파에 대한 민감도는 `CORD_IMPULSE_SCALE`(0.16). 전선(1.0)과 같은 값을 주면 빗나간
  총알마다 요란하게 출렁인다.
- 스치기만 해도 흔들린다 (`Room.notify_shot` → `LampLight.apply_shot`).
- 램프가 움직이면 라이트·빛 기둥·바닥 풀이 따라가고, `PropShadow` 가 매 프레임 광원 위치를 다시 읽으므로
  **프랍 그림자가 통째로 쓸린다.** 정적인 조명이 못 만들던 공간감이 여기서 나온다.
- 늘어뜨림 길이는 `LampLight.CORD_DROP`(118px). 층고가 낮은 방에서는 `Room._add_pendant_lamp` 가
  천장~바닥 거리의 32% 까지로 줄인다.

진폭은 `HIT_KICK` 이 정한다. 진자 주기 `T=2π√(L/g)` 에서 `θ≈v/(L·ω)` 이므로 줄 118px·중력 1900 에서
110 이 약 13°다. 240(≈28°)은 눈에 거슬릴 만큼 컸다.

**흔들림이 과하거나 부족하면 이 세 개를 만진다** (`scripts/lamp_light.gd`):
`CORD_WIND`(평소) · `HIT_KICK`(맞았을 때) · `CORD_IMPULSE_SCALE`(스친 총알).

## 주의

- `height` 가 0 이면 빛 방향이 표면과 평행해져 **노멀맵이 아예 반응하지 않는다.** 면 라이팅을 보고 있다면
  여기를 먼저 확인한다 (`Docs/FACE_LIGHTING.md`).
- 램프를 세게 올리면 청크당 라이트 한도(15)에는 영향이 없지만 글로우 임계(0.85)를 넘겨 번질 수 있다.
  광원 **개수**를 늘릴 때는 `tools/light_budget.gd` 를 돌려야 한다 (`scripts/lighting.gd` 주석 참고).
- `lighting/tuning.json` 은 커밋 대상이다. 저장한 값이 팀 전체의 게임 화면을 바꾼다.
