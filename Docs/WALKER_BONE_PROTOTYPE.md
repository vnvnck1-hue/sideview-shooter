# 원화 기준 사족보행 본 프로토타입

로비의 **사족보행 랩 — 피벗 · 키프레임 편집**은 `GodotPrototype/scenes/WalkerLab.tscn`을 연다. 지금은 [피벗과 키프레임 작성 도구](WALKER_AUTHORING.md)가 기본 화면이다. 이 문서는 최초 골격의 해석과 절차적 보행 검증을 설명한다. 인게임 `WalkerUnit`의 아트 리그 교체 전이며, 기존 인게임용 동작은 `scenes/WalkerLegacyLab.tscn`에서 비교할 수 있다.

## 기존 골격 검사 모드 조작

아래 키는 `authoring_enabled=false` 또는 자동 캡처 모드의 기존 검사 UI 기준이다. 작성 도구의 최신 조작은 [사용 안내](WALKER_AUTHORING.md)를 따른다.

| 입력 | 동작 |
|---|---|
| A/D 또는 ←/→ | 좌우 이동. 원화의 사선 시점 유지 |
| Shift | 달리기 |

| 마우스 / 좌클릭 | 포신 독립 조준 / 발사선 표시 |

## 원화와 해석

기준은 첨부된 1536×1024 원화와 동일한 `assets/reference/walker_original.png`다. SHA-256은 `198caf260a0f20dd7bee454172fdbdd9be42f549548aa0657c8ac0304faebcc8`. 다른 측면 변환 이미지나 기존 컷아웃을 쓰지 않는다. `walker_anatomy.gd`의 좌표는 이 이미지의 원본 픽셀 좌표이며, 표시 때만 전체에 동일한 0.42 배율을 적용한다.

| 색 | 구조 |
|---|---|
| 노랑 | 몸체 중심, 하부 프레임에서 고관절로 내려오는 연결 |
| 보라 | 상부 몸통 |
| 하늘 | 포가 회전축 → 포신 뿌리 → 총구 |
| 산호 | 고관절 → 무릎의 짧은 연결 암 |
| 초록 | 무릎 → 발목의 긴 장갑 다리 |
| 파랑 | 발목 → 발끝 |

- **NF**: 가까운 앞다리. 중앙 아래의 둥근 축에서 연결 암이 위로 꺾이고, 큰 장갑 다리는 다시 아래로 내려온다.
- **NR**: 가까운 뒷다리. 오른쪽 아래 원형 축에서 짧은 암이 위·바깥으로 꺾인 뒤 긴 장갑 다리가 발목으로 내려온다.
- **FF**: 먼 앞다리. 왼쪽의 좁은 다리. 먼 다리는 어둡게 표시한다.
- **FR**: 겹쳐 가려진 접힌 다리를 네 번째 다리로 해석한 **추정 구조**. 점선으로 표시한다. 원화 대조에서는 들린 원래 위치를 유지하며, 보행에서는 별도 지면 목표로 내린다.

관절 번호는 0 프레임 연결, 1 고관절, 2 무릎, 3 발목, 4 발끝이다. 보이지 않는 프레임 내부 연결은 점선이며 가려진 다리 관절은 열린 관절 링으로 표시한다. 가려진 고관절·무릎·포가 축의 기계적 구조는 한 장의 원화만으로 확정할 수 없으므로 이 골격은 검토 가능한 해석이다.

## 구현

`reference_walker.gd`는 실제 `Skeleton2D` 아래 몸체·상부·포가·포신 4개와 다리별 4개, 총 20개의 `Bone2D`를 생성한다. 다리는 프레임 연결 → 고관절 → 연결 암 → 장갑 다리 → 발 순서다. 두 마디 IK와 회전하는 골반 연결 암을 모두 고정 길이로 풀며 기존 가변 길이 유압 막대나 그림의 축소·늘리기를 사용하지 않는다. 네 다리가 같은 지면에 닿도록 보행 몸 높이를 도달 범위 안에서 정한다. 지지하는 발이 미끄러지지 않도록 몸의 이동량을 제한하고, 착지 순간 확정한 발 위치는 다음 스텝까지 고정한다. 원화의 기준 본 자세는 보행이나 초기화로 덮어쓰지 않는다.

`reference_walker_view.gd`는 계산된 관절 좌표를 그대로 그린다. 원화의 사선 시점은 좌표에 이미 반영되어 있어 추가 yaw 사영·좌우 뒤집기를 하지 않는다. `reference_walker_lab.gd`는 입력, 지형, 카메라, 원화 겹치기, 범례를 담당한다. 조준은 하체 보행과 분리하며 포가 축과 포신 축의 간격까지 보정한다.

## 재현

프로젝트 루트에서 설치된 Godot 실행 파일로 실행한다.

```text
godot --headless --path GodotPrototype --script res://tools/validate_reference_walker.gd
godot --headless --path GodotPrototype --script res://tools/validate_reference_lab.gd
godot --path GodotPrototype --rendering-method gl_compatibility --audio-driver Dummy --fixed-fps 60 --script res://tools/capture_reference_walker.gd
```

렌더 캡처는 숨긴 창의 SubViewport에서 실제 랩 UI까지 그린다. 원화 대조·기본 자세·좌우 보행·점프 스틸과 15fps 프레임은 `GodotPrototype/tools/artifacts/reference_walker/`에 저장된다.

검증은 30/60/120Hz에서 원화 관절과 실제 Bone2D 끝점, 고정 길이, 접지 고정, 대각선 보행 순서, 평지·경사·턱, 실제 랩 왕복, 점프·착지, 8방향 조준과 이동 반대 방향 사격을 확인한다. 별도 씬 검증은 로비 경로를 통해 실제 씬을 생성하고 키 입력으로 이동·원화 전환·점프·초기화·정지·로비 복귀를 확인한다. 도달 범위가 짧은 다리에 맞추어 지형에서 이동이 감속될 수 있으며, 달리기 설정값은 보장 속도가 아닌 상한이다.
