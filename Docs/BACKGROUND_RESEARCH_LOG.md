# 배경 리서치·비교 분석·시안 결정 기록

기록일: 2026-09-22. 범위: 메탈슬러그 배경 구성·소실점 조사 → 현재 게임 비교 → 대형 정비홀 재설계 → 전력 릴레이실 → 상호작용 톤 분리 → 향후 제작 방향 합의.

**이 문서는 근거와 결정 과정의 기록이다.** 이후 제작 기준은 [BACKGROUND_ART_DIRECTION](BACKGROUND_ART_DIRECTION.md), 개별 결과의 최신 선택·승인 상태는 [ART_ASSET_STATUS](ART_ASSET_STATUS.md)에서 관리한다. 최종 결론과 맞지 않는 초기 제안도 지우지 않고, 어느 시험에서 수정되었는지 남긴다.

## 1. 최종 결론 요약

1. 우리 게임에는 **정비홀 v1 계열의 얕은 사이드뷰 공간**이 맞는다. 가로로 큰 건축과 설비는 좋지만 바닥·근경을 넓혀 깊은 공간을 만드는 방향은 채택하지 않는다.
2. 메탈슬러그에서 배울 것은 모든 원근·화면비의 복제가 아니라 **큰 형태, 앞뒤 가림, 픽셀 면의 조직, 게임 대상의 시각적 위계**다.
3. 방별 기능에 맞는 프랍과 근경을 새로 그릴 수 있다. 기존 검은 상자·기둥·작업대를 그대로 반복할 필요는 없다.
4. 배경과 상호작용 프랍은 구별되어야 한다. 단, **프랍의 고유색을 바꿔 구별하는 방식은 사용자 선호가 아니다.** 이후에는 고유색을 보존하고 배경 명암·배후 면·윤곽·기능 부위의 위계부터 다룬다.
5. 전력실 v2는 구분 효과 때문에 **현재 상태를 유지**한다. 노란/황토색 재도색 자체를 선호한 것은 아니며, 미래 제작의 색상 규칙으로 승격하지 않는다.
6. 아래 네 장은 생성 콘셉트다. 엔진 규격 검증·모듈화·반입·실제 인터랙션 구현은 별도다.

### 스케일·픽셀·렌더 진단

- 당시 idle 기준 불투명 높이 267 월드 px × 0.75 ≈ 200 화면 px, 세로 화면의 약 22%. 분리형 머리/몸통의 자세에 따라 달라진다. MS X 표본의 서 있는 인물 약 17%는 이미지상 근사치이며 동일 체형·동작의 엄밀한 비교가 아니다.
- 캐비닛 불투명 높이 260 월드 px는 위 인물 기준과 비슷했다. 줌만 0.75→1.0으로 올리면 인물이 세로의 약 30%가 되므로 여백 해결을 위해 일괄 확대하지 않는다.
- 아트 셀 4 월드 px × 줌 0.75 = 화면 3px. 약 747×300 아트 셀 상당의 시야지만 렌더 출력 자체는 2240×900이다.
- 작업실 캐비닛/작업대/의자와 인물 분리 파츠는 맞는 원점에서 4×4 단색 블록. 작업실 벽은 16가지 원점 검사 모두에서 블록 내부 색 변화가 있었다. 검체 분석실 벽/작업대는 4×4 블록이며 각각 불투명 RGB 5색/9색이었다. 이것은 해당 샘플 관측이며 품질 순위·새 팔레트 상한이 아니다.
- 3×2 배경 패널은 위상 고정 반복이다. 당시 줌의 반복 주기는 화면 288×192px. 무작위 타일 선택으로 설명하지 않는다.
- 배경 z0~4 / 인물 z5~6 / 근경 z7, 전경 상대 이동 계수 1.045가 이미 있었다.
- 접지선 아래 하단 프레임 50 월드 px → 화면 37.5px는 프레임 두께다. 원근상 전체 지면 깊이와 같은 값이 아니다.
- 당시 CRT 아케이드 설정과 월드 출력은 별도로 확인했다. 원작 JPEG와 출력 조건이 달라 픽셀 선명도의 수치 우열이나 원작 애니메이션 빈도는 주장하지 않았다.

### 소실점 해석 정정

‘눈높이는 화면 40~55%’, ‘중앙 소실점 하나가 메탈슬러그의 규칙’, ‘물체별 소실점은 자유로우므로 눈높이도 제각각 가능’은 현재 결론이 아니다. 발 접지선·산 능선·화면 중심을 지평선으로 혼동하지 않는다. 같은 방향의 평행 모서리는 같은 소실점으로 모이고, 방향이 다른 물체는 소실점이 달라도 된다. 계단 경사선은 수평 지면의 소실선과 구분한다. 실제 참고 이미지의 공통 소실점을 신뢰할 만큼 확정하지 못해 비교 그림에는 설명용 기하 도식을 사용했다.

## 4. 시안과 사용자 피드백의 시간순 기록

아래 인용은 이 작업의 사용자 피드백이다. 앞선 요청이 후속 판단으로 수정되었을 때 **후속 판단을 최종 기준**으로 남긴다.

### A. 대형 정비홀 v1 — 큰 구조와 얕은 공간

기존 정비홀의 반복 벽을 큰 서비스 베이·골조·덕트·크레인으로 재구성했다. 수평 이동선과 캐릭터의 큰 비중, 좁은 바닥을 유지했다.

- [결과](../research-images/comparison/hall-redesign-v1.png) · [전체 생성 프롬프트](../research-images/comparison/hall-redesign-v1-prompt.md).
- 첫 피드백: “공간은 넓어져서 좋은데”라고 평가하면서 바닥과 근경의 공간감을 더 시험하고, 프랍도 새로 그려 달라고 요청했다.
- 이후 v2를 본 뒤 “오히려 직전에 그려준게 우리에겐 맞는 것 같아”라고 **v1 공간 방향으로 복귀**했다.
- 해석: v1은 공간/그림체 참조다. 구도상의 선호를 개별 프랍·팔레트·전체 납품 승인으로 확대하지 않는다.

### B. 대형 정비홀 v2 — 바닥·근경 확장 시험, 미채택

기존 바닥과 프랍을 버리고 캐릭터 접지선을 약 3/4 높이로 올렸다. 넓은 지면, 큰 전경 케이블 드럼·곡관, 새 모터 운반대·유압 장비로 깊이를 늘렸다.
