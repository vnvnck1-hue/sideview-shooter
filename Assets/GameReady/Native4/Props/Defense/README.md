# Sentry Turret v1

첨부된 센트리 터렛 구조를 참고한 사이드뷰 방어 프랍이다. 바닥 또는 벽 개구부에서 돌출되는 하부 베이스와 탄약 드럼, 별도 회전 발사부, 별도 급탄 벨트로 나뉜다.

## 리소스 구성

- `sentry_turret_base_v1.png` — 고정 베이스. 하부 장갑 개구부, 원통형 탄약 드럼, 상부 회전 소켓 포함.
- `sentry_turret_firing_v1.png` — 회전 발사부. 총열·리시버·조준 블록 포함. 베이스와 분리해 회전시킨다.
- `sentry_turret_ammo_feed_v1.png` — 황동 탄약이 보이는 U자형 급탄 벨트. 베이스 드럼과 발사부 사이에 배치한다.

## 권장 배치

- 발사부 회전축: `sentry_turret_firing_v1.png`의 좌측 중앙, 약 `(12, 28)` native px.
- 베이스 결합점: 베이스 상단 소켓 중앙, 약 `(56, 12)` native px.
- 발사부는 회전축을 기준으로 `0°`일 때 우측을 향한다. `rotation`만 변경하고 위치 피벗은 고정한다.
- 급탄 벨트는 발사부와 함께 회전시키지 않고, 양 끝 커넥터를 베이스 드럼 포트와 발사부 하부 급탄구에 각각 맞춘다. 회전 각도에 따라 길이·곡률이 바뀌는 경우 이 리소스를 변형하거나 별도 벨트 프레임을 추가한다.

모든 Native4 PNG는 투명 배경, 알파 0/255, 4px 월드 블록 규격으로 정리되어 있다. `GodotPrototype/assets/props/defense/`에는 ×4 nearest 적용본이 있다.
