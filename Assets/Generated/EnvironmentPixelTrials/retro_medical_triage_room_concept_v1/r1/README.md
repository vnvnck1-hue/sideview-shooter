# 초기 비교 — 채택하지 않음

세 프랍에 사용한 `Tolerance=12 / Snap=20 / Coherent=true / Passes=3` 설정을 방 전체 원본에 적용한 첫 시험이다. 기술 검사는 통과했지만 넓은 벽과 외곽 암부의 작은 명도 차이가 지나치게 큰 색면으로 묶이는 것을 시각 검토에서 확인했다.

따라서 제출본으로 채택하지 않는다. 다음 `r2`에서는 동일한 원본·격자·알고리즘을 유지하고 색 허용 오차만 4로 낮춰 미세한 명암을 더 남긴다. 원본은 수정하지 않았다. 이 폴더는 실패 비교 기록으로 보존하며 승인된 프랍 프로세스의 공통 설정을 변경하지 않는다.
