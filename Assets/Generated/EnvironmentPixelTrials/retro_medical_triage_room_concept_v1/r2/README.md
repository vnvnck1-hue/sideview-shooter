# 레트로 의료 처치실 — 픽셀 크기 3배 / 4배

**이후 사용자 피드백:** “너무 깨진다. 그냥 2배로 하자.” 이 두 후보는 기본 선택에서 제외했다. 최신 결과는 [2배 재제작](../two-x-r1/README.md)이다. 아래는 이전 비교 기록이다.

입력: `Assets/Generated/Environments/retro_medical_triage_room_concept_v1.png`, **1672×941**, SHA256 `FFF87BB13E201C0B628B3E200FD78249406AC5C77D7D4212D5338A3C2D08011E`.

사용자 요청대로 방 전체를 같은 보존형 Aseprite 프로세스로 3배·4배 격자에 옮겼다. 원본의 가구 배치·구도·벽·배관·커튼·조명을 포함하며 별도 오브젝트 분리나 방 재설계는 하지 않았다. 원본과 기존 승인된 프랍 파일은 변경하지 않았다. 이 두 결과는 사용자 선택 전 후보이며 게임 반입은 미실행이다.

## 처리와 자산별 조정

1. 원본을 [source.png](source.png)에 해시가 같은 상태로 동결 복사했다.
2. 기존 `preserve_crisp_prop.lua`로 원본색 기반 색 군집과 평균 없는 경계 정리를 했다. 해당 알고리즘 자체와 승인된 프랍의 설정/파일은 수정하지 않았다.
3. 초기 r1의 `Tolerance=12`는 방 전체의 넓은 암부를 너무 큰 색면으로 합치는 문제가 있어 채택하지 않았다. 이 방에서는 **Tolerance=4**로 줄여 채널 차이 4, 명도 차이 2.2 이내에서 유사색을 묶었다. `Snap=20 / Coherent=true / Passes=3`은 유지했다. 경계색 묶기는 기존 알고리즘의 별도 조건을 따르므로 모든 출력 픽셀의 변화가 4 이하라는 뜻은 아니다. 이는 원본 보존을 위한 이 자산의 설정이며 모든 자산의 공통값 변경이 아니다.
4. 3배와 4배는 같은 전체 해상도 준비 결과에서 독립적으로 만들었다. 3배 후보를 다시 줄여 4배를 만들지 않는다. 큰 셀에서 색면의 면적 지지를 계산하고 실제 원본색 하나를 고른다. RGB 평균색·전역 대비 증폭·디더링·새 디자인은 없다.
5. Aseprite 문서로 저장하고 다시 열어 PNG를 내보내 검증했다.

전체 해상도의 참조/색 군집/경계 레이어는 [준비 Aseprite](prepared/retro_medical_triage_room_concept_v1.aseprite)에 남아 있다. 작은 최종 문서는 숨김 `center_sample_reference`와 표시 `coverage_selected_pixels`의 두 레이어다.

## 실제 관찰과 한계

- 방의 구도, 의료 캐비닛, 두 침대, 가림 커튼, 세면대, 계기판, 모니터, 조명 위치와 기본 색 관계는 유지된다.
- 3배는 작은 서랍 손잡이·담요 주름·커튼 고리의 묘사가 상대적으로 더 남는다. 4배는 픽셀 덩어리가 크고 미세 마모와 선이 더 많이 합쳐진다.
- **의료 모니터의 가는 파형·작은 표시, 계기판 눈금, 가는 금속 반사광은 일부 끊기거나 사라진다.** 확대판에 이 손실을 숨기지 않았다. 새 파형이나 부품을 임의로 그려 넣지는 않았다.
- 색 오차를 줄인 r2도 원본의 연속적인 암부·광량 변화를 이산적인 색면으로 묶는 차이가 있다. 완전 무손실 복사나 모든 세부의 동일 보존을 보장하지 않는다. 원본의 화면상 물체 크기 대비 남는 화소 수가 앞선 독립 프랍과 달라 보존 수준도 같다고 가정할 수 없다.
- 이 결과는 방 전체 그림의 픽셀화다. 타일/프랍 분리, 충돌, 피벗, 엔진 배율 조정이나 런타임 교체는 수행하지 않았다.

## 검증

[verification.json](verification.json)에 원본/변환기/산출물 SHA256, 설정과 지표를 기록했다.

- 원본 및 동결 복사본 해시 유지.
- 원본 기반 준비 문서의 숨김 참조·3개 레이어·RGB/단일 프레임·이진 알파 검사 통과.
- 두 후보의 Aseprite 재열기·2개 레이어 상태·치수·합성/PNG RGBA 전 픽셀 일치 검사 통과.
- 네 면의 투명 여백, 출력 알파 0/255, 원본에 없는 출력 RGB 0개.
- 실루엣 IoU 1.0은 이 원본이 방 전체 불투명 직사각형이어서 성립하는 값이다. 내부 가구 윤곽이나 디테일 보존율로 해석하지 않는다.
