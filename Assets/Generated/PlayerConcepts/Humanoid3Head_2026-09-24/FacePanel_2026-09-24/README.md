# UNIT-7 발광 얼굴 패널 3안

사용자 제공 이미지 `user_face_reference.png`를 기준으로 얼굴 전면의 노란 발광 패널만 변형한 확대 콘셉트 원화다. 짙은 기체, 파란 작업복, 짧은 인간형 비율, 귀 모양 센서, 오른쪽 측면 자세를 유지했다.

| 파일 | 얼굴 차이 |
|---|---|
| `01_rounded_panel.png` | 검은 테두리 안에 둥근 세로형 단일 패널 |
| `02_slanted_panel.png` | 앞쪽으로 기울어진 사다리꼴 패널과 얇은 턱판 |
| `03_split_panel.png` | 큰 윗면·작은 아랫면으로 나뉜 2구획 패널 |

세 안은 내장 이미지 생성 도구로 각각 사용자 이미지에서 편집했다. 실제 네이티브 게임 스프라이트로 픽셀·팔레트·알파 검수한 상태는 아니다.
