# UNIT-7 인간형 3등신 콘셉트

사용자 피드백에 따라 이전의 큰 체형 변형을 줄이고, 세 안 모두 평범한 인간형 몸 구조와 약 3등신 비율로 다시 그렸다. 기준은 `AI_Robot_Base_Narrative_Design_Notes.md`와 `Docs/OPENING_FLOW.md`: 무장 없이 깨어나는 회사 소유 AI 로봇, 교체 가능한 몸체, 아직 정해지지 않은 원래 역할.

| 파일 | 차이 |
|---|---|
| `unit7_service_android_v1.png` | 회백색 얼굴 외피, 황갈색 작업 재킷, 호박색 단안 센서 |
| `unit7_hooded_worker_v1.png` | 기존 붉은 후드를 짧게 정리한 작업자형, 작은 호박색 바이저 |
| `unit7_facility_attendant_v1.png` | 남청색 시설 작업복과 모자형 외피, 청록색 단안 센서 |

세 이미지는 내장 이미지 생성 도구의 별도 프롬프트로 제작했다. 공통 지시는 **머리·몸통·짧은 다리가 각각 키의 약 1/3**, 평범한 두 팔·두 다리, 엄격한 오른쪽 측면, 빈손의 조용한 자세, 굵은 1990년대 런앤건풍 픽셀 덩어리였다. 각 안의 머리 덮개와 작업복만 다르게 지정했다.

검토용 확대 원화이며 실제 80×80 art px 게임 스프라이트로 픽셀 정리·색 수 검증·엔진 반입한 결과는 아니다.
