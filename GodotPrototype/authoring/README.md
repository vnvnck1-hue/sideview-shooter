# 로봇 작성 데이터

사족보행 랩의 **Ctrl+S**는 `walker_gait.json`에 관절 각도·보폭·스텝 시간 등 보행 설정을 저장한다. 테스트씬과 다음에 생성되는 인게임 로봇이 함께 읽는다.

상단 **피벗 · 키프레임** 편집기의 **Ctrl+S**는 `walker_motion.json`에 피벗 원화 좌표와 동작별 키프레임을 저장한다. 기존 원화 편집 데이터는 보행 수치 조정으로 변경되지 않는다.

사용 방법: [보행 튜닝](../../Docs/WALKER_TUNING.md), [피벗·키프레임 편집](../../Docs/WALKER_AUTHORING.md).
